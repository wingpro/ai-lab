六种调度方式

先看适用情境，再展开提示词。复制后交给你正在使用的 AI。
01 / OUTPUT MODE

受控文字

先理解概念，再建立结构。

适用：术语太多，句子太绕

短句 · 单义 · 名称一致
展开可直接使用的提示词

这里的“80%”是放宽写作约束的口令，不是合规评分。中文借用清晰表达原则，不等同于正式 ASD-STE100 英文规范。

02 / OUTPUT MODE

图 / 认知图

让结构承担解释功能。

适用：字都看懂，却看不出关系

模块 · 连线 · 关系标签
展开可直接使用的提示词

箭头不自动代表因果。要求区分“导致”“先后”“包含”和“相关”，证据不足的关系用虚线标记。

03 / OUTPUT MODE

交互 HTML

把阅读变成主动探索。

适用：想展开细节、比较或试参数

全局地图 · 展开 · 探索
展开可直接使用的提示词

交互应回答一个问题。不要只添加动画；参数演示需标明假设、单位和适用范围。

04 / OUTPUT MODE

讲解视频

沿时间展开推理，让变化可见。

适用：静态图仍讲不清动态过程

问题 · 动画推理 · 理解检查
展开可直接使用的提示词

这是一种视觉解释方法。实际渲染、配音可能需要额外工具；先审脚本，避免把错误做成精致视频。

05 / OUTPUT MODE

压缩成判断

从材料中提炼可用的结论。

适用：理解之后，需要记住和行动

判断 → 一页纸 → 一句话
展开可直接使用的提示词

压缩越强，信息损失越大。保留可回溯的证据与条件；一句话用于记忆，一页纸用于决策。

06 / OUTPUT MODE

审查 AI 输出

把理解与监督放在同一闭环。

适用：答案很顺，但不知道能否相信

事实 · 假设 · 证据 · 边界
展开可直接使用的提示词

让模型自查能暴露问题，但不能替代独立验证。关键事实回到原始资料，关键计算另行复算。

关于这个小工具

快刀 AI Lab · 001｜Karpathy 式 AI 调度菜单，帮助你根据理解障碍选择输出方式，并生成可复制的调度提示词。本页面不调用 AI，也不自动生成答案。

隐私说明

无需登录、不收费。主题替换、问题选择和审查勾选全部在浏览器本地处理；本页面不上传用户输入，不使用统计追踪、Cookie 或本地存储，刷新后状态重置。

复制操作会把提示词写入设备剪贴板。你主动粘贴到其他 AI 服务后，内容按该服务的规则处理。未来如通过网址访问，托管方可能记录基础访问日志，但本页面不会主动发送你的输入。

内容依据所引用对话整理。“Karpathy 式”表示方法启发：受控文字、图、HTML、视频来自对话中的分享；压缩、审查、复述与 8 条口令为实用改写，并非 Karpathy 官方提示词清单。
页面只在本地运行，不上传输入；主题与勾选状态在刷新后重置。视频模块提供调度模板，本页面不生成视频。
