# ai-lab

## Karpathy 式 AI 调度菜单

**不知道怎样让 AI 帮你理解？先选出你卡住的问题，再换一种输出方式。**

这是一个打开即用的中文单页工具。它帮助你根据当前的理解障碍，选择合适的 AI 调度方式，生成提示词（Prompt），复制后交给你正在使用的 AI。

👉 **在线体验：** [打开 AI 调度菜单](在这里替换为你的在线网址)

无需登录 · 不收费 · 输入在浏览器本地处理

## 它能帮你做什么？

有时候，AI 已经写了很多，我们仍然没看懂。问题可能出在输出形式：概念需要讲清，关系需要画出来，动态机制需要沿时间展开。

本工具保留六种调度方式：

| 你现在遇到的问题 | 推荐方式 | 用途 |
|---|---|---|
| 术语太多，句子太绕 | 受控文字 | 用短句、简单词汇和一致名称解释概念 |
| 字都看懂，却看不出关系 | 图 / 认知图 | 看清模块、层级、流程与关系 |
| 想展开细节、比较或试参数 | 交互 HTML | 通过点击、比较和参数交互主动探索 |
| 静态图仍讲不清动态过程 | 讲解视频 | 用脚本、分镜与视觉推理解释变化 |
| 理解之后，需要记住和行动 | 压缩成判断 | 提炼核心判断、一页纸和一句话 |
| 答案很顺，但不知道能否相信 | 审查 AI 输出 | 检查事实、来源、假设、计算和边界 |

另外提供：

- **理解地图**：查看不同输出形式与理解闭环。
- **六项审查清单**：采纳 AI 输出之前，逐项核查。
- **八条快捷调度口令**：点击即可复制完整提示词。

## 怎么使用？

1. **填写主题（选填）**  
   例如：“Agent 如何完成任务？”填写后，提示词中的 `【主题】` 会自动替换。

2. **选择当前问题**  
   点击最符合你现状的选项，查看推荐方式。

3. **复制 Prompt**  
   点击“复制推荐 Prompt”，也可以展开卡片查看完整内容。浏览器不允许自动复制时，页面会提供手动复制窗口。

4. **粘贴到你正在使用的 AI**  
   根据需要补充材料、背景或用途，再让 AI 执行。

5. **审查结果，再形成自己的判断**  
   核查关键事实与适用边界，并尝试用自己的话复述。

无需按顺序使用六种方式。你可以从当前最需要的一种开始，发现理解缺口后再切换。

## 一个使用例子

你想理解“Agent 如何完成任务”，但 AI 的回答堆满了术语。

在页面中填写主题，选择“术语太多，句子太绕”，复制“受控文字”提示词，让 AI 先把概念讲清楚。

如果概念已经理解，却仍看不出各环节之间的关系，再切换到“图 / 认知图”。获得结果后，使用审查清单检查来源、假设与边界。

## 审查清单

页面提供六项核查：

- 关键事实有可追溯来源
- 来源日期与情境适用
- 事实、推断、建议已分开
- 数字、单位与计算已复核
- 假设、反例与边界已检查
- 能够用自己的话复述

**勾选进度只代表核查完成度，不代表答案可信度。** 模型自查可以帮助发现问题；关键事实仍需回到原始资料，关键计算需要另行复核。

## 八条快捷口令

每条口令都会复制对应的完整提示词，并带入你填写的主题。

1. 80% STE100，给我讲明白。
2. 别堆文字，画一张认知图。
3. 做成可交互的 HTML 驾驶舱。
4. 用 3Blue1Brown 式视觉推理讲清楚。
5. 压缩成判断、一页纸、最后一句话。
6. 先审查，再采纳。
7. 用一个具体例子和一个反例检验我的理解。
8. 按我的背景定制，理解后让我复述。

部分模板保留 `【背景】`、`【用途】` 等占位符，请在粘贴到 AI 后自行补充。

## 隐私与数据

- 无需登录，不收费。
- 主题替换、问题选择和审查勾选均在浏览器本地处理。
- 页面不上传用户输入，不使用统计追踪、Cookie 或本地存储。
- 刷新页面后，主题、选择与勾选状态会重置。
- 复制操作会将提示词写入设备剪贴板。
- 主动粘贴到其他 AI 服务后，内容按该服务的规则处理。
- 通过托管网址访问时，托管平台可能记录基础访问日志；本页面不会主动发送你的输入。

## 本地使用与部署

这是一个自包含的单页 HTML，样式与交互脚本都在文件内：

- 不需要安装依赖或运行构建命令。
- 不需要服务器、数据库或 AI API 密钥。
- 下载 HTML 后，可用浏览器直接打开，离线使用页面功能。
- 可通过 GitHub Pages 等静态网站托管服务发布。
- 如果希望通过网站根地址打开，将上线副本命名为 `index.html`。

页面已针对手机竖屏优化。微信内访问效果与自动复制能力，仍可能受到网络和浏览器权限影响。

## 方法来源与功能边界

“Karpathy 式”表示方法启发，并非 Karpathy 官方产品或官方提示词清单。受控文字、图、HTML、视频来自所参考对话中的分享；压缩、审查、复述与八条口令为实用改写。

“80% STE100”是放宽写作约束的口令，不是合规评分。中文模板借用清晰表达原则，不等同于正式 ASD-STE100 英文规范。

本页面负责选择方式和生成提示词，不调用 AI，也不自动生成答案、认知图、交互页面或视频。实际产出取决于你使用的 AI 服务及其工具能力。
